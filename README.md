Power BI Dashboard: Global Air Quality Analysis

Project Overview

This project was completed as Task 3 of my Data Analyst Internship at SWYNEX Technologies. The objective was to use Microsoft Power BI to explore and visualise the Global Air Pollution Dataset through an interactive dashboard.

The dashboard presents key air quality indicators, category distributions, pollutant-specific measurements, and country-level comparisons.

Key Dashboard Features

- Average AQI: Displays the overall average Air Quality Index (AQI).
- Total AQI Records: Summarises the number of records analysed.
- AQI Category Distribution: Compares the frequency of records across air quality categories.
- Average AQI by Pollutant: Visualises the average values of the pollutant-specific measurements included in the analysis.
- Average AQI by Country: Presents geographical differences in average AQI across the countries represented in the dataset.
- AQI Category Filter: Allows users to filter the dashboard by air quality category.

Tools Used

- Microsoft Power BI
- Global Air Pollution Dataset

Key Findings

- The overall average AQI was approximately 72.01.
- The Good category contained 9,936 records, while the Moderate category contained 9,231 records.
- Average AQI varied across the countries represented in the dataset.
- The dashboard provides a visual overview of AQI patterns and pollutant-specific measurements.

These findings describe the available dataset and should not be interpreted as definitive assessments of current air quality in each country.
